# Quarto Print Assets

This repository includes the specifications for the printable assets.

Board:
- A4 portrait
- 4x4 grid
- Maximum practical size
- Thick black grid lines
- Print at 100%

Rules:
- A4 portrait
- Objective
- Piece attributes
- How to play
- Winning
- Draw
- Reminder that you choose your opponent's piece.

Combined:
- Page 1: Board
- Page 2: Rules
