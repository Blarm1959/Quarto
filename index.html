How to play

Choose a piece for your opponent. They place it on any empty square, then choose the next piece for you.

Choose how many features can create a win. The fixed progression is:

1. Colour
2. Colour + Height
3. Colour + Height + Shape
4. Classic. Colour + Height + Shape + Hollow

Make a row, column or diagonal of four pieces sharing one of the enabled features. You can also optionally allow matching 2×2 squares as wins.

Classic rules use all four features and do not include 2×2 square wins.
